# 프로토타입 공개 점검표

## 저장소 점검

- 공개 폴더가 `D:\DEV\Lumate-public`인지 확인함
- 원본 프로젝트 폴더에서 직접 `git init` 또는 `git push`하지 않음
- 커밋 목록에 `.gd`, `.py`, `.ps1`, `.tscn`, 모델과 캐릭터 원본이 없는지 확인함
- 개인 경로, 사용자 이름, API 키와 토큰 문자열을 검색함

## 실행 파일 점검

- 새로 만든 릴리스 빌드만 사용함
- 실제 펫 실행 파일의 앱 이름과 아이콘이 Friend인지 확인함
- 캐릭터 제작 실행 파일의 앱 이름이 Maker인지 확인함
- 기본 캐릭터와 포함 가능한 캐릭터 자산의 배포 권한을 확인함
- API 키가 환경변수에서만 읽히는지 확인함
- 다른 컴퓨터에서 첫 실행, 설정, 종료와 삭제를 확인함
- Windows 보안 경고와 코드 서명 여부를 기록함

## 핵심 코드 보호 점검

- 배포 EXE에 평문 Python 작업기가 포함되는지 확인함
- 보호 대상 GDScript가 PCK에서 추출될 가능성을 확인함
- 공개 프로토타입에서 Maker를 제외할지 결정함
- 포함해야 하는 핵심 로직은 GDExtension DLL 또는 서버 API로 옮긴 뒤 배포함

## 릴리스 점검

- 버전 번호와 변경 기록을 갱신함
- ZIP과 실행 파일의 SHA256을 `checksums` 문서에 기록함
- 제3자 라이선스와 모델 이용 조건을 함께 제공함
- 알려진 제한사항과 자동 생성 결과의 실패 가능성을 적음
- 공개 저장소 Releases에만 공식 파일을 첨부함
