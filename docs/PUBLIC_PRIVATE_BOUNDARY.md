# 공개 저장소와 비공개 원본 경계

## 공개 저장소에 포함함

- 제품 소개와 사용법
- 변경 기록
- 개인정보·보안 안내
- 공개가 허용된 스크린샷과 영상
- 릴리스 파일의 SHA256 체크섬
- 오류 제보 양식
- 제3자 라이선스 목록

## 비공개 원본에만 보관함

- Friend와 Maker의 Godot 프로젝트 전체 원본
- Friend의 캐릭터 행동과 상호작용 GDScript
- Maker의 캐릭터 생성·검수·모션 제작 Python 작업기
- LoRA 학습과 모델 설치 PowerShell 스크립트
- 테스트용 컨셉아트와 생성 결과
- 캐릭터 원본 시트와 유료·개인 자산
- 빌드 인증서, 토큰과 계정 정보
- 사용자 데이터와 작업 프로젝트

## 실행 파일의 한계

공개 저장소에서 소스를 제외해도 Godot 리소스와 스크립트는 실행 파일에서 분석될 가능성이 있음. Python 작업기를 실행 파일에 포함하면 사용자 컴퓨터에 복사되는 과정에서 원문을 확인할 수도 있음.

프로토타입에서는 문서·릴리스 전용 공개 저장소와 비공개 원본 저장소를 분리함. 장기적으로 보호가 필요한 알고리즘은 다음 중 하나로 이동함.

1. 컴파일된 GDExtension DLL
2. 별도 로컬 네이티브 실행 모듈
3. 인증된 서버 API

컴파일은 분석 난도를 높일 뿐 완전한 비밀을 보장하지 않음. 가장 강한 보호가 필요한 로직은 서버에서 실행하고 클라이언트에는 입력·출력 규격만 제공함.

## 공개 전 금지 항목

- `D:\DEV\desktop-pet` 또는 `D:\DEV\desktop-pet-character-studio`를 공개 저장소로 직접 푸시하지 않음
- `.godot`, `Build`, `Temp`, 모델, 학습 결과와 사용자 프로젝트를 커밋하지 않음
- `PROJECT_STATE.md`는 개인 경로와 내부 작업 기록이 있으므로 공개판에 복사하지 않음
- 현재 Friend 또는 Maker 프로토타입 EXE를 핵심 코드 보호가 끝났다고 오해한 채 배포하지 않음
