# Lumate

코덱스와 연결 가능한 우리의 친구.

Lumate는 데스크톱 펫과 캐릭터 제작 도구를 함께 제공하는 Windows용 프로젝트고 만들고 난 후 ai로 코드를 정리해서 여기 내용과 코드가 조금 다른부분들이 있을 수 도 있음

Lumate는 두 앱으로 구성됨.

- `Friend`: 화면 위에서 움직이고 상호작용하는 실제 데스크톱 펫 앱
- `Maker`: 컨셉아트로 Friend용 캐릭터 팩을 만드는 별도 제작 앱

현재 프로토타입 범위:

- 투명 창 위에서 움직이는 애니메이션 캐릭터
- 클릭, 드래그, 먹이, 수면과 여러 감정 반응
- 캐릭터별 성격과 로컬 대화
- 캐릭터 팩 교체 구조
- Codex 작업 상태에 반응하는 선택 기능
- 별도 캐릭터 제작 앱 Maker 실험

## 다운로드

검증된 프로토타입이 준비되면 이 저장소의 Releases에서 제공할 예정임.

현재 저장소에는 실행 파일이 아직 등록되지 않았음. 출처가 다른 비공식 실행 파일은 사용하지 않는 것을 권장함.

## 지원 환경

- Windows 10 또는 Windows 11
- Friend 실행에는 별도 Python이 필요하지 않음
- Maker는 NVIDIA RTX GPU와 넉넉한 저장 공간을 권장함

## 프로토타입 제한사항

- Maker의 자동 캐릭터 제작은 실험 기능이며 입력 캐릭터와 다른 후보가 생성될 수 있음
- 자동 검수에서 탈락한 후보는 완성 캐릭터로 제공하지 않음
- sd 캐릭터 변환과 고품질 모션 생성은 계속 개선 중임
- 배포 전 캐릭터 이미지와 외부 모델의 이용 조건을 확인하고 쓰셈

이 저장소는 배포, 문서, 변경 기록과 오류 제보를 위한 공개 저장소임. 핵심 생성·학습·상호작용 구현의 원본 소스는 포함하지 않음.

실행 파일에 포함된 구성요소를 분석하거나 재배포할 수 있다는 허가를 의미하지 않음. 자세한 내용은 `NOTICE.md`에 적어놨으니 보셈.
